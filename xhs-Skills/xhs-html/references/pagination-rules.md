# 确定性分页校准参考（Pagination Rules）

> 2026-11-14 增补：来源 fxyadela/write-then-publish「一篇正文自动生成 6 张卡片」的分页形态提炼（个人非商业许可，仅方法论）。用途：LLM 拆页时的**确定性校准清单**——页数方案（6/7/8/9）仍按 SKILL.md 主流程与用户确认，本文件管"内容到页的切分与防溢出硬规则"。

## 断点优先级（从高到低）

1. **章节边界**（H2/H3）：天然页界，优先在此断页
2. **段落边界**：章节过长时按段落断
3. **句子边界**：段落仍超限时按句断，断句处保留完整语义（禁切半句）
4. **禁断点**：代码块、表格、字段清单、步骤组**不得跨页**——放不下就整块移次页或先压缩

## 每页容量硬限（与 SKILL.md「页面密度」对账）

| 项 | 硬限 | 超限动作 |
|---|---|---|
| 正文 | 70–150 中文字符 | 先删次要说明 → 再压缩间距 → 最后才拆页（顺序不可反） |
| 标题 | 首图 88–128px / 内页 60–76px 一行放下 | 标题超一行先改写标题，不改字号 |
| 卡片阵列 | 相邻两页禁完全相同阵列 | 变换组件类型保持节奏 |
| 留白 | 内页必须保留明显留白 | 溢出优先砍内容不砍留白 |

## 孤行与寡行

- 页尾只剩 1 行正文（孤行）或页首只有 1 行接尾（寡行）→ 调整断点到上一段边界；
- 列表项不得在页尾拆成"标题在上一页、首项在下一页"；
- 编号步骤组必须整组同页（步骤 1-3 与 4-6 可分页，单步不可拆）。

## 自动页数校准（LLM 拆页自查表）

拆完页后逐项自查，任一不过回改：

- [ ] 每页正文在 70–150 字硬限内（表格/代码按视觉占用判断）
- [ ] 无跨页的代码块/表格/步骤组
- [ ] 无孤行寡行
- [ ] 封面信息最少、结果预览页紧随封面（页序合同不变）
- [ ] 总页数落在用户选定档位（6/7/8/9），不为凑页数稀释密度，不为省页数硬塞
- [ ] 最后一页是验收/复用/总结，非空泛口号

## 与上游工具的关系

- 溢出的**机检**用 `scripts/render_xhs.mjs`（尺寸/溢出/越界元素）；
- 导出 PNG 用 `dragon__html-cards-to-png`（跨平台零依赖）；
- 本文件是**规则层**，两个脚本是**机检/导出层**——规则先于机器，机器复核规则。
